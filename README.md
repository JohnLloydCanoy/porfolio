# JLC.dev | Personal Portfolio 🚀

> *"Building something out of nothing."*
Welcome to the repository for my personal portfolio! This site serves as a central hub for my software development projects, UI design work, and community engagements. It is designed to be blazingly fast, fully responsive, and highly maintainable.

---

## ✨ Features

- **Modern UI/UX:** Dark-themed aesthetic utilizing glassmorphism, smooth CSS transitions, and interactive hover states.
- **Lightning Fast:** Built with Astro's island architecture, shipping zero JavaScript by default for maximum performance.
- **Fully Responsive:** Fluid layouts that scale perfectly from mobile devices to ultrawide desktop monitors.
- **Dynamic Sections:**
- **Projects Showcase:** Highlights my core work including *ASAP*, *Project A.N.I.*, *STAYNET*, and *DocuLens*.

- **Skills Grid:** A scalable overview of my frontend, backend, and design toolkit.

- **Leadership Timeline:** Highlights my roles at the University Student Government and as Founder of the 4-H Club chapter.
- **Direct Contact:** Integrated form and direct communication channels.

---

## 🛠️ Tech Stack
This portfolio was designed and developed from scratch using:
- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)
- **Design Tools:** Figma & Adobe Photoshop
